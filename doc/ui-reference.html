応用情報技術者試験 学習支援

処理を1ステップずつ進めて、
「なぜそうなるのか」を理解する。

文章だけでは追いにくいアルゴリズムや内部状態の変化を、処理の流れに沿って可視化する学習アプリです。 教材表示時に生成される同じ配列を使って複数のアルゴリズムを切り替え、結果だけでなく途中経過を確認します。

学び方

結果を見るだけで終わらない学習フロー

教材ごとに、初期状態から最終結果までを順番に確認します。

1

初期状態・条件を確認

教材で使うデータと、何を理解するための教材なのかを最初に確認します。

2

処理を1ステップずつ実行

その時点で何を比較・処理しているかと、状態がどう変化したかを見比べます。

3

結果の理由まで確認

最終結果だけでなく、「なぜそうなるのか」「そこから何が分かるか」を確認します。

MVP教材

ソートアルゴリズム可視化

7種類のソートを切り替え、同じ配列がそれぞれの規則で整列されていく様子を1ステップずつ確認します。

UI確認用プロトタイプ：認証・問題演習・学習分析・自由入力は含みません。教材固有Domainと本番状態管理はこのHTMLのJavaScript構造を流用しません。

Learning Materials

学習一覧

利用できる可視化教材から、確認したい内容を選びます。

MVPでは教材は1件のみです。カード型の一覧構造にしているため、教材情報を追加した場合も同じ形式で並べられることをUI上で確認できます。
